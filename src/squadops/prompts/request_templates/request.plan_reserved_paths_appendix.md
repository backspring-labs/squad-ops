## Paths this product's owner reserves: plan no task there

The product's owner changes the paths below themselves and has reserved them from a cycle's
change. Plan no task whose `expected_artifacts` name one, whatever the task would do there. A
task that does is refused at the plan gate and the framing is re-run, and a run that changes one
is refused at delivery.

If the work can't be done without changing one, plan what can be done without it and say in
the task's description what is left for the owner.
